# E-Commerce Web Application

A Flask-based e-commerce web application with user authentication, product management, cart, checkout, and order features.

## Features

* User Registration & Login
* Admin Login
* Product Management
* Add to Cart
* Update Quantity
* Checkout
* Order Management
* Invoice Generation
* Session Authentication

## Tech Stack

* Python
* Flask
* MySQL
* HTML
* CSS
* JavaScript

## Run Project

pip install requirements.txt

python app.py
